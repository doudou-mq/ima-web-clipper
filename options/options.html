    ℹ️ 关于

    IMA Web Clipper 浏览器扩展

    版本：v1.0.0

    技术栈：Manifest V3 · 原生 JS · Readability.js · Turndown.js


    功能：

    • 📄 三种剪藏模式：完整 / 选区 / URL
    • 📝 自定义 Markdown 模板（支持 YAML frontmatter）
    • ⌨️ 快捷键 Ctrl+Shift+S / Cmd+Shift+S
    • 🖱️ 右键菜单快速剪藏
    • 🔐 分级安全存储（Session / Local）
    • 📂 知识库树形浏览与文件夹选择
